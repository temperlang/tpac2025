# TPAC 2025 Breakout: Lightweight Standards via Cross-Translating PLs

Slides and resources for the w3c TPAC 2025 Breakout Session titled
*[Lighter weight standards processes by using a cross-translating PL to
craft reference implementations][breakout issue]*.

The *Templates* directory contains the slides.  The slide templates
continue to use that directory name, and trying to change the
directory structure would just unnecessarily create potential for
bugs.

(Slide templates courtesy [mgifford/w3c-tpac-template] from [Talks/TPAC/Templates/])
